## Operational limits

SMTP acceptance means provider transport acceptance, not mailbox delivery. Already-started network sends can race revocation, but the old invitation source becomes unusable; no DB transaction spans SMTP. Reset/verification sources are global account records; member/owner invitation evidence is tenant scoped and platform owner recovery requires SuperAdmin authority. Permanent source audit fences survive operational email retention.

No live mailbox, real provider TLS/authentication, sender DNS or deployment validation was performed. Email defaults disabled; live rollout requires selected service/sender, securely configured SMTP credentials and separate payload key, verified DNS/connectivity and explicit worker enablement. Local test credentials/canaries are synthetic; original env files and old shared book activations were not changed. Browser fixtures use disposable DBs and unoccupied loopback services; cleanup waits for backend shutdown before plain DROP.
